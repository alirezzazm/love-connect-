# لاو کانکت (Love Connect)

اپلیکیشن آشنایی و دوستیابی — **فقط فرانت‌اند**. هیچ سرور، دیتابیس یا API‌ای در کار نیست؛
همهٔ داده‌ها در `localStorage` همان مرورگر ذخیره می‌شود و پروفایل‌های نمونه از یک فایل
استاتیک خوانده می‌شوند.

## امکانات نسخهٔ فعلی

| بخش | توضیح |
| --- | --- |
| کشف (`/`) | کارت پروفایل‌ها را با کشیدن به چپ/راست یا دکمه‌ها رد یا لایک کن. اگر طرف مقابل هم تو را پسندیده باشد، مودال «مچ شدید!» باز می‌شود. |
| مچ‌ها (`/matches`) | فهرست کسانی که با آن‌ها مچ شده‌ای، همراه با آخرین پیام هر گفتگو. |
| گفتگو (`/chat/[id]`) | چت متنی با هر مچ. طرف مقابل با پاسخ‌های آماده و کمی تأخیر جواب می‌دهد (چون بک‌اندی نیست). |
| پروفایل (`/profile`) | ویرایش نام، سن، شهر، شغل، بیو و علاقه‌مندی‌ها + پاک کردن همهٔ داده‌ها. |

رابط کاربری فارسی و راست‌به‌چپ است و برای موبایل طراحی شده (عرض حداکثر `max-w-md`).

## استک

- **Next.js 15** با App Router
- **React 19** + **TypeScript**
- **Tailwind CSS 4** (پیکربندی از طریق `@theme` داخل `globals.css`)
- **Zustand 5** با میان‌افزار `persist` برای نگه‌داری وضعیت در `localStorage`

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
```

ساخت نسخهٔ پروداکشن:

```bash
npm run build && npm start
```

## نکته‌ها

- عکس پروفایل واقعی وجود ندارد؛ به‌جایش برای هر نفر یک گرادیان رنگی با حرف اول نام
  ساخته می‌شود تا پروژه به هیچ فایل یا سرویس بیرونی وابسته نباشد.
- فیلد `likesYouBack` در `src/lib/profiles.ts` تعیین می‌کند لایک تو به مچ تبدیل شود یا نه.
- چون بک‌اندی نیست، احراز هویت واقعی، آپلود عکس و پیام‌رسانی بلادرنگ در این نسخه وجود ندارد.
  اضافه کردن آن‌ها گام بعدی است.

## گام‌های بعدی (پیشنهاد)

1. احراز هویت با شمارهٔ موبایل و کد یک‌بارمصرف
2. آپلود عکس پروفایل
3. بک‌اند واقعی (Prisma + دیتابیس) و چت بلادرنگ با WebSocket
4. فیلتر جست‌وجو بر اساس سن، شهر و علاقه‌مندی
5. گزارش تخلف و پنل ادمین
